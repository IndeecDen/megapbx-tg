# Changelog

Все значимые изменения проекта фиксируются в этом файле.

## [megapbx-tg-v0.1.1] — 2026-09-24

### Добавлено

- Интерактивный установщик для Debian/Ubuntu: `install.sh`.
- Установка Python-зависимостей, системного пользователя и systemd-сервиса.
- Настройка reverse proxy через Nginx и опциональная установка TLS-сертификата.
- Валидация конфигурации, health-check и безопасные права на `.env`.
- Автоматические тесты, Ruff и CI workflow.
- Документация по установке, обновлению, откату и безопасной публикации секретов.

### Исправлено

- Telegram API теперь проверяет `ok` и HTTP-статус.
- Добавлены retry для временных ошибок Telegram.
- Повторные webhook с одним `callid` не создают повторные уведомления в пределах процесса.
- Счётчик откатывается, если отправка уведомления не удалась.
- Исправлено ошибочное закрытие нового звонка повторным событием старого.
- Удалено логирование raw payload, персональных данных и токенов.
- Добавлено HTML-экранирование и защита webhook от пустой конфигурации.

### Ограничения

- Состояние звонков пока хранится в памяти процесса.
- При обновлении необходимо перезапустить `megapbx-tg.service`.
- Перед production-развёртыванием используйте HTTPS и не публикуйте `.env`.
